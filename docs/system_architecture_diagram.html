🔄 Data Processing Pipeline

1
File Upload & Validation
Check file size (≤10MB), format (PDF/DOCX/TXT/Images), industry type
2
Rate Limit Check
Verify IP hasn't exceeded 5 daily uploads, increment counter
3
Document Type Detection
Determine if PDF is searchable or scanned, route to appropriate processor
4
Text Extraction
PyPDF2 for searchable PDFs, OCR pipeline for scanned documents/images
5
AI Analysis
Send extracted text to GPT-4.1 with industry-specific prompts
6
Result Processing
Parse JSON response, extract risk score, store in database
7
Response Generation
Format analysis results, calculate processing time, return to client

🛠️ Image Preprocessing Steps:

  • Resize large images (max 2000px)
  • Convert to grayscale
  • Enhance contrast (1.5x)
  • Apply sharpening filter
  • Convert to binary (black/white)
  • Memory optimization with garbage collection
